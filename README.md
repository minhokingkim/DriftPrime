# DriftPrime

DriftPrime orchestrates real-time data processing and auto-scaling for event-driven applications with a centralized data-driven controller.

DriftPrime is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/DriftPrime.git`
2. `cd DriftPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DriftPrime, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
